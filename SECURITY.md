# Security policy

## Supported versions

Security fixes are currently provided for the latest `0.7.x` release.

## Reporting a vulnerability

Please report security problems privately through GitHub's **Security → Report a vulnerability** form. Do not publish sensitive details in a public issue.

Include the affected macOS version, LaceDrop version, steps to reproduce the problem and any relevant crash report. Reports that can be reproduced will be investigated before public disclosure.
