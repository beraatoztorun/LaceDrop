# Contributing

Bug reports and focused pull requests are welcome.

1. Fork the repository and create a branch for your change.
2. Keep changes small and explain the user-visible effect.
3. Build the project on macOS 13 or newer with `zsh build.sh`.
4. Confirm that both `build/LaceDrop.app` and `build/LaceDrop.saver` are created.
5. Open a pull request with reproduction or testing notes.

Do not include generated build folders, application bundles, ZIP archives or personal signing credentials in commits.
